# Módulo 3 — Desenvolvimento Orientado a IA: Do Prompt ao Deploy

## O que este módulo cobre

Este módulo ensina como usar ferramentas de IA para criar sites, páginas, protótipos e ferramentas digitais funcionais — mesmo sem saber programar uma única linha de código.

Você vai aprender o processo completo: da ideia inicial até um produto publicado online, usando ferramentas gratuitas ou com plano gratuito generoso.

## Por que criar sem programar mudou o jogo para iniciantes

Por décadas, criar qualquer coisa digital exigia aprender linguagens de programação. Isso significava anos de estudo antes de conseguir publicar algo funcional. A barreira era gigantesca — não de talento, mas de tempo e acesso.

Hoje, ferramentas como Lovable, v0 e Cursor permitem que qualquer pessoa descreva o que quer em português e receba código funcional em segundos. O que um desenvolvedor experiente levaria dias para construir, você constrói em uma tarde — conversando com IA como se fosse um colega de trabalho.

Isso não é hype. É o mesmo salto que aconteceu quando máquinas de escrever viraram processadores de texto, ou quando máquinas fotográficas analógicas viraram smartphones. A habilidade que importa mudou: não é mais saber digitar cada linha de código — é saber o que pedir, como avaliar o resultado, e como iterar até chegar onde você quer.

## O que você consegue fazer ao terminar este módulo

Ao concluir o Módulo 3, você será capaz de:

- Criar uma landing page completa sem tocar em código manualmente
- Usar ferramentas de IA para gerar interfaces, formulários e páginas funcionais
- Publicar um site gratuitamente em plataformas como Vercel, Netlify ou GitHub Pages
- Iterar e melhorar um projeto digital usando prompts em vez de contratações
- Entregar projetos simples para clientes usando exclusivamente IA como desenvolvedor
