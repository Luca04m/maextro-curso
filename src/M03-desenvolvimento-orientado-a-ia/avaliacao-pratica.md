# Avaliação Prática — Módulo 3

## Objetivo

Ao completar esta avaliação, você terá criado e publicado uma página web real acessível por URL pública. Este não é um exercício simulado — o resultado existe na internet e pode ser mostrado para qualquer pessoa.

---

## O que você vai entregar

Uma landing page funcional publicada online com URL pública.

---

## Tarefas específicas

### Tarefa 1 — Especificação documentada

**O que fazer:** Crie um documento com a especificação do projeto antes de começar a criação.

**Critério de conclusão:**
- [ ] O documento existe (pode ser um arquivo .txt, .md ou página no Notion/Google Docs)
- [ ] Contém: objetivo do projeto, público-alvo, tom de comunicação, estrutura de seções e CTA principal
- [ ] Contém: pelo menos um prompt fundador escrito antes de abrir qualquer ferramenta

---

### Tarefa 2 — Criação com ferramenta de IA

**O que fazer:** Use uma das ferramentas do módulo (Lovable, v0, Cursor ou equivalente) para criar a landing page a partir do seu prompt.

**Critério de conclusão:**
- [ ] A landing page foi criada usando IA como principal ferramenta de desenvolvimento
- [ ] O código foi gerado por IA (não copiado manualmente linha a linha de tutoriais externos)
- [ ] Você realizou no mínimo 3 rodadas de iteração com prompts específicos

---

### Tarefa 3 — Qualidade visual e estrutural

**O que fazer:** Revise o resultado final contra os critérios de qualidade do módulo.

**Critério de conclusão:**
- [ ] A página tem no mínimo 5 seções distintas
- [ ] Existe pelo menos um CTA (call-to-action) claramente visível
- [ ] Não há texto placeholder visível (nenhum "Lorem ipsum" ou "[NOME DA EMPRESA]" não substituído)
- [ ] O visual está coerente — mesma paleta de cores, mesmo estilo nas seções
- [ ] Existe pelo menos uma imagem ou elemento visual (pode ser placeholder de banco de imagens gratuitas como Unsplash)

---

### Tarefa 4 — Funcionamento mobile

**O que fazer:** Teste a página em um dispositivo mobile real ou em modo de simulação mobile no browser.

**Critério de conclusão:**
- [ ] A página é legível em celular sem zoom forçado
- [ ] Os botões são clicáveis (tamanho adequado para toque — mínimo 44px de área de toque)
- [ ] O menu funciona em mobile (ou some e reaparece como menu hamburguer)
- [ ] Nenhum conteúdo está cortado ou sobreposto em tela de 375px de largura

---

### Tarefa 5 — Elemento interativo funcionando

**O que fazer:** Implemente e teste pelo menos um elemento interativo.

**Critério de conclusão (qualquer um dos abaixo):**
- [ ] Botão de WhatsApp configurado com número real e mensagem pré-preenchida, ou
- [ ] Formulário de contato que envia dados reais (via Netlify Forms, Formspree ou equivalente), ou
- [ ] Menu de navegação com âncoras que rolam a página suavemente até as seções corretas

---

### Tarefa 6 — Deploy e URL pública

**O que fazer:** Publique a landing page em uma plataforma de hosting gratuita.

**Critério de conclusão:**
- [ ] A página está acessível por uma URL pública (subdomínio `.lovable.app`, `.netlify.app`, `.vercel.app`, `.github.io` ou equivalente)
- [ ] A URL funciona em um browser diferente do seu (teste em modo anônimo)
- [ ] A URL funciona em um celular que não é o seu (ou em rede de dados diferente da sua)
- [ ] A página carrega em menos de 5 segundos em conexão 4G

---

### Tarefa 7 (integradora) — Landing page de portfólio publicada

**O que fazer:** Execute o projeto completo da Aula 7 — uma landing page apresentando você como criador de sites com IA.

**Critério de conclusão:**
- [ ] A landing page apresenta você pelo nome real
- [ ] A proposta de valor (o que você faz e para quem) está clara no hero
- [ ] Existe uma seção com pelo menos 2 serviços e seus respectivos preços ou "a partir de"
- [ ] Existe uma seção de portfólio com pelo menos 2 exemplos (podem ser projetos fictícios criados durante o módulo)
- [ ] Existe um meio de contato funcionando (WhatsApp, formulário ou email)
- [ ] A página está publicada e acessível por URL pública
- [ ] Você consegue, em 30 segundos, enviar o link para alguém e ela consegue acessar sem instrução adicional

---

## Critério de aprovação do módulo

Para considerar o Módulo 3 concluído, você precisa completar:

- As Tarefas 1 a 6 com todos os critérios marcados
- A Tarefa 7 (integradora) com todos os critérios marcados

Não existe nota numérica — a avaliação é binária: o critério está cumprido ou não está.

---

## O que não é aceito como conclusão

- Screenshot de uma página que não está publicada
- Link que requer login para acessar
- Projeto criado copiando código de tutoriais existentes sem usar IA como ferramenta principal
- Página com texto placeholder não substituído
- Página que não funciona em mobile

---

## Dica para quem travar

Se você travar em qualquer etapa, o caminho de volta é sempre o mesmo: volte ao último estado que funcionava e identifique a mudança específica que causou o problema.

Se o projeto inteiro parar de funcionar: volte ao histórico de versões (Lovable) ou ao último commit funcional (GitHub).

Se a IA estiver gerando resultados inconsistentes: comece uma nova conversa fornecendo o contexto do projeto do zero.

Se o deploy não funcionar: tente uma plataforma diferente. Lovable, Netlify e Vercel têm processos diferentes e um deles vai funcionar.
