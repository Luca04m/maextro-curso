# Avaliação Prática — Módulo 2: Engenharia de Prompts

## Como funciona esta avaliação

Esta avaliação não é uma prova. É um conjunto de tarefas práticas que validam se você sabe fazer — não apenas se você sabe falar sobre fazer.

Você conclui o módulo quando completar as 5 tarefas abaixo. Cada tarefa tem um critério de conclusão claro. A tarefa 5 integra tudo que foi aprendido.

Não existe nota. Existe entregado ou não entregado.

---

## Tarefa 1 — Diagnóstico de Prompts Ruins

**O que fazer:**

Pegue 3 prompts que você já usou ou que representam como você pediria algo normalmente. Para cada um:
1. Escreva o prompt original
2. Identifique qual(is) dos 5 componentes está faltando (tarefa, contexto, restrições, exemplos, formato)
3. Reescreva o prompt incluindo os componentes ausentes
4. Execute as duas versões (original e reescrita) e compare os resultados

**Critério de conclusão:**
- 3 pares de prompts (original + reescrito)
- Para cada par: identificação dos componentes ausentes e resultado comparativo em 2-3 linhas
- O prompt reescrito precisa gerar um resultado visivelmente superior ao original

**O que esta tarefa valida:** Que você consegue diagnosticar a qualidade de um prompt e melhorá-lo de forma intencional, não por tentativa e erro cega.

---

## Tarefa 2 — Cadeia de Iteração Documentada

**O que fazer:**

Escolha uma tarefa de negócio complexa — uma proposta, um script de vendas, um post de lançamento, um SOP. Execute o processo de iteração completo:

1. Escreva o prompt inicial
2. Execute e avalie o resultado usando as perguntas de avaliação da Aula 5
3. Escreva o diagnóstico específico (o que está errado e por quê)
4. Reformule o prompt e execute novamente
5. Repita pelo menos 3 vezes, documentando cada rodada

Entregue o documento com:
- Prompt rodada 1 + resultado + diagnóstico
- Prompt rodada 2 + resultado + diagnóstico
- Prompt rodada 3 + resultado final
- Conclusão: o que aprendeu sobre esse tipo de tarefa ao longo das rodadas

**Critério de conclusão:**
- Mínimo 3 rodadas documentadas
- Diagnóstico específico (não "ficou ruim" — mas "o tom estava X porque faltou Y")
- Resultado final da rodada 3 é utilizável (você usaria em um contexto real)
- Conclusão com ao menos um aprendizado aplicável a prompts futuros

**O que esta tarefa valida:** Que você entende e pratica o ciclo de iteração — não só o conceito, mas o processo real com diagnóstico e refinamento.

---

## Tarefa 3 — Banco de Prompts Inicial

**O que fazer:**

Crie o banco de prompts inicial para o seu negócio ou área de atuação:

1. Configure a ferramenta de organização (Notion, Google Docs, arquivo de texto — o que funcionar para você)
2. Crie as categorias relevantes para seu contexto
3. Escreva o prompt de contexto do seu negócio (usando o template da Aula 7)
4. Documente no mínimo 8 prompts — ao menos 2 de cada uma dessas categorias: comunicação com clientes, conteúdo, vendas

Para cada prompt, use o formato completo: nome, categoria, quando usar, prompt com variáveis marcadas, resultado esperado, notas.

**Critério de conclusão:**
- Banco estruturado com categorias criadas
- Prompt de contexto completo e específico para o seu negócio
- 8+ prompts documentados no formato completo
- Ao menos um prompt de cada categoria obrigatória (comunicação, conteúdo, vendas)
- Cada prompt já foi testado e funciona (não são hipotéticos)

**O que esta tarefa valida:** Que você está construindo um ativo real — não apenas aprendendo teoria sobre como construir.

---

## Tarefa 4 — Fluxo Completo de Trabalho

**O que fazer:**

Execute um fluxo completo de 3 ou mais etapas para um entregável real. O entregável deve ser algo que você vai usar de verdade — não um exercício fictício.

Opções de entregável:
- Proposta comercial completa para um cliente real ou simulado com características reais
- Calendário editorial de 2 semanas com pelo menos 10 posts completos
- Plano de lançamento de um serviço com as principais peças de comunicação
- Documento de processos (SOPs) para uma área do seu negócio

Para o fluxo:
1. Liste as etapas antes de executar (decomposição)
2. Execute etapa por etapa, documentando o que foi produzido em cada uma
3. Identifique como o contexto foi mantido entre etapas
4. Anote qual etapa foi a mais crítica para a qualidade do resultado final

**Critério de conclusão:**
- Entregável finalizado que você usaria em um contexto real
- Registro das etapas executadas (pelo menos 3)
- Nota sobre como o contexto foi mantido
- O entregável passou por revisão humana (você verificou fatos, adequação de tom, precisão)

**O que esta tarefa valida:** Que você consegue usar IA para produzir entregáveis completos, não apenas respostas isoladas.

## Tarefa 5 — Tarefa Integradora: Projeto de 5 Dias

**O que fazer:**

Durante 5 dias consecutivos, use IA para um projeto contínuo do seu negócio e documente o processo. O projeto deve exigir pelo menos:

- Um fluxo com 3+ etapas
- Pelo menos 3 tipos de prompts diferentes (geração, revisão, análise, transformação, conversação)
- Iteração real (não somente o primeiro resultado)
- Revisão e julgamento humano em pelo menos dois pontos

**Possíveis projetos:**
- Criação completa de uma campanha de captação de clientes (posts + e-mails + proposta)
- Estruturação de um novo serviço (definição, precificação, scripts de venda, conteúdo de lançamento)
- Diagnóstico e plano de melhoria de uma área do negócio
- Produção do conteúdo do mês completo (posts + roteiros de vídeo + newsletter)

**Entrega:**
Um documento com:
1. Descrição do projeto e objetivo
2. Diário de 5 dias: o que você fez cada dia, quais prompts usou, o que funcionou e o que não funcionou
3. Entregáveis produzidos (ou links para eles)
4. Reflexão final: quais habilidades do módulo você mais usou? O que ainda sente que precisa praticar?

**Critério de conclusão:**
- 5 dias de registro documentado
- Pelo menos 3 tipos diferentes de prompts utilizados
- Entregáveis concretos produzidos
- Reflexão honesta com identificação de pontos fortes e fracos

**O que esta tarefa valida:** Que você integra todas as habilidades do módulo em um projeto real, com a IA funcionando como copiloto genuíno — não como ferramenta ocasional.

---

## Quando você está pronto para o Módulo 3

Você está pronto quando:

- Consegue escrever um prompt com os cinco componentes sem precisar consultar o checklist
- Itera resultados com diagnóstico — não apenas "tente de novo"
- Tem um banco de prompts funcionando com ao menos 8 prompts documentados
- Completou pelo menos um fluxo de múltiplas etapas com resultado utilizável
- Verifica fatos antes de usar qualquer dado específico gerado pela IA

Não precisa ser expert. Precisa ter essas habilidades como hábito básico.

---

## Nota sobre honestidade

Estas tarefas são para você, não para aprovação externa. Fazer de forma superficial para "cumprir" não tem custo imediato — mas vai aparecer como déficit de habilidade nas semanas seguintes quando as tarefas ficarem mais complexas.

Se uma tarefa ficou difícil, releia a aula correspondente. Se ainda ficou difícil, pratique mais antes de avançar. O módulo 3 assume que as habilidades deste módulo estão internalizadas.
