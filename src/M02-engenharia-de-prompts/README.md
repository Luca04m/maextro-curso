# Módulo 2 — Engenharia de Prompts & Fluxos com IA

## O que este módulo cobre

Este módulo ensina como se comunicar com modelos de IA de forma precisa e produtiva. Você vai aprender desde o mecanismo interno de como os modelos funcionam até como construir fluxos de trabalho reais, revisar resultados e criar um banco de prompts que economiza horas toda semana.

Prompt engineering não é sobre truques. É a habilidade de traduzir sua intenção em instrução clara o suficiente para que a IA produza o que você precisa — na primeira ou segunda tentativa, não na décima.

## Por que prompt engineering é a habilidade central de quem usa IA

Quando você usa IA sem saber criar prompts, você está no banco de passageiro. A ferramenta te leva para algum lugar, mas não necessariamente onde você precisa ir.

Quem domina prompts está no volante.

A diferença é concreta: o mesmo modelo de IA, recebendo pedidos diferentes sobre o mesmo problema, pode gerar desde um texto inútil e genérico até uma solução que te poupa três horas de trabalho. O modelo não mudou. O que mudou foi a qualidade da instrução.

Estudos com equipes que usam IA mostraram ganhos de 20% a 80% de produtividade. A variação é quase toda explicada pela qualidade dos prompts — não pelo modelo usado.

Empresas como a Microsoft reportaram que entre 20% e 30% do código em seus repositórios hoje é gerado por IA. Esse percentual cresce a cada mês. Quem sabe direcionar a IA ganha terreno rápido.

## O que você consegue fazer ao terminar este módulo

Ao concluir as 8 aulas, você será capaz de:

- Explicar como um modelo de linguagem funciona — o suficiente para saber quando confiar nele e quando questionar
- Construir um prompt eficaz usando as cinco dimensões: tarefa, contexto, restrições, exemplos e formato
- Identificar qual tipo de prompt usar para cada situação: geração, explicação, revisão, transformação
- Criar fluxos de trabalho do início ao fim — do pedido ao entregável revisado
- Usar IA como copiloto real: não só gerar, mas iterar e refinar resultados
- Escrever prompts para tarefas de negócio: e-mails, propostas, conteúdo, análises
- Organizar e reutilizar seus melhores prompts em um banco pessoal
- Reconhecer e corrigir os erros mais comuns que desperdiçam tempo com IA
