# Módulo 7 — Infraestrutura de Negócio Solo BR

## O que este módulo cobre

Este módulo ensina tudo o que você precisa para operar como profissional solo no Brasil de forma legítima, organizada e sustentável. Não é teoria de negócios — é o chão de fábrica: como abrir o MEI, como cobrar, como entregar, como se comunicar e como manter uma rotina sem se perder.

Infraestrutura não é o que você vende. É o que sustenta tudo que você vende.

## Por que infraestrutura importa desde o primeiro cliente

A maioria das pessoas espera ter "volume suficiente" para se organizar. Esse é o erro. Quando o segundo cliente chega, você já precisa ter o processo do primeiro funcionando. Quando o décimo cliente chega, você precisa ter o processo dos nove anteriores rodando.

Profissional solo sem estrutura perde tempo explicando o que já deveria estar documentado, cobra errado porque não calculou o custo real, e perde clientes porque não gerencia expectativa.

Estrutura cria credibilidade. Credibilidade cria preço. Preço cria sustentabilidade.

## O que o aluno consegue fazer ao terminar

- Abrir o MEI pelo GOV.BR sem pagar nada
- Emitir nota fiscal eletrônica para clientes
- Definir o preço mínimo de qualquer serviço usando lógica objetiva
- Criar uma proposta profissional em português simples
- Operar com stack 100% gratuito (Notion, Google, WhatsApp Business, Canva, Trello)
- Comunicar atrasos e mudanças sem travar
- Manter uma semana operacional com blocos claros para não virar escravo do urgente
